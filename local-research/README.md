# Investigación local de AMARU

Coloque aquí copias de los archivos que desea indexar en el observatorio.

- Los originales nunca se modifican, renombran ni eliminan.
- Se admiten JSON, JSONL, CSV, TSV, YAML, XML, RSS, Atom, TXT, Markdown, HTML, PDF, DOCX, XLSX y metadatos de imágenes.
- El OCR está desactivado de forma predeterminada.
- Cambie `LOCAL_RESEARCH_DIR` en el archivo local e ignorado `.env.local` si prefiere usar otra carpeta.
