# Data sources

The active source is `Biblioteca local`, attributed to private user-provided files and disabled for public redistribution. External source records are not enabled in the current milestone.

Every future source must record configuration state, frequency, last success/failure, attribution, terms URL, and explicit personal-use/public-display/commercial/redistribution/historical-storage flags. Ambiguous terms default to private local use with public redistribution disabled.

Missing API credentials must produce `not_configured`. Authorized RSS, OAI-PMH, official datasets, documented APIs, and permitted HTML extraction are valid adapter types; invented endpoints are not.
